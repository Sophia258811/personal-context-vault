# Security

This prototype stores personal evidence in plaintext. Use a controlled local environment.
Keep `.pcv/`, exports, profiles, agent task files, browser data and credentials out of Git.
Do not open issues containing private browsing content, tokens or database files.
Use synthetic reproductions. For sensitive vulnerabilities use GitHub private vulnerability
reporting if enabled, or request a private contact channel without disclosing exploit details.

Known limitations and data lifecycle boundaries are documented in
`docs/PRIVACY_AND_SECURITY.md`, `docs/BROWSER_COMPANION.md` and `docs/AGENT_HANDOFF.md`.
