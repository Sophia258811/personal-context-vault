# 2026-11-01 开发总结

## 已实现

- 来源、证据、声明和复核的本地 SQLite 基础；撤销、删除及审计。
- ChatGPT 用户消息/获授权完整对话、抖音导出、通用 JSON/Markdown/文本导入。
- 文件目录轮询，连接器注册/暂停，外部 ID 与内容哈希去重。
- Chrome/Edge Manifest V3 浏览器扩展：主动启动、可见正文采样、同站导航重新注入、跨站限制、暂停。
- 仅监听回环地址的 HTTP 接收端、每次启动独立配对码、限长输入、原子 JSON 写入。
- Agent 文件任务协议：准备任务、证据哈希核验、来源有效性检查、原子录入、重复结果幂等；候选画像默认待确认。
- 内容与观察分离的整合函数，保留平台、授权来源、模态和多次观察；尚未接入实时导入流程。

## 实际验证

- 一次真实浏览测试产生 7 条可见文字快照并入库；同一内容的播放进度变化仍会形成多条观察。
- 当前 Agent 处理其中一条证据并录入一条摘要，未产生画像候选。公开仓库不包含此次原始内容、摘要或账户数据。
- HTTP 集成测试覆盖认证拒绝、非法输入、中文正文、文件写入、证据导入、重复同步和撤销。
- JavaScript 模拟验证同站导航、跨站隔离、来源地址和暂停；真实浏览器导航/生命周期的完整验收仍待完成。
- Agent 测试覆盖哈希拒绝、幂等、来源撤销、候选待确认；整合测试覆盖稳定 ID、重复观察、平台与来源隔离。
