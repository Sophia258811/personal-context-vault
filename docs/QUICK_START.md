# 一键启动（Windows 原型）

需要 Python 3.11+（含 tkinter）与 Chrome/Edge。尚不是签名安装包；浏览器首次加载扩展和授予站点权限需用户操作，不会通过脚本绕过。

## 首次使用

1. 双击项目根目录 Start-PCV.cmd。一个窗口自动准备来源、连接器，运行接收端与入库程序，不需分别执行 CLI。
2. 在扩展管理页加载 browser-extension；已安装旧版则点击重新加载，并刷新网页。
3. PCV 窗口点击“复制首次配对码”，在扩展设置中粘贴。点击 **开始采集** 并确认浏览器的站点权限。默认只添加当前站点。

## 日常使用

点 **开始采集** 或 **继续采集**，扩展会按需启动本机 PCV。自动启动需要注册一次，从 Chrome 扩展管理页复制 PCV 扩展 ID，在项目目录执行 `.\Start-PCV.ps1 -ChromeExtensionId <扩展ID>`。扩展目录移动导致 ID 变化时重新注册。也可双击 Start-PCV.cmd 手动启动。

已授权站点的新标签、刷新及跳转可继续采集文字。只有前台可见且有焦点的页面被记录。最小化 PCV 窗口继续运行，关闭窗口停止接收和入库。点击 **暂停采集** 会暂停所有站点的文字和音画采集，直到手动恢复。

### 流媒体音画

需要 Chrome 116+ 和新版 PCV 接收端。在抖音、哔哩哔哩或 YouTube 页面打开工具栏中的 PCV，点击主按钮即可一起启动文字和音画采集。关闭弹窗，保持视频在前台有声播放。扩展约每 6 秒取一段音频和一张播放器区域关键帧。只有能绑定到明确内容 ID、连续播放且在前台的片段才会入库。

使用 **暂停采集** 可结束本次录制。离开标签、页面跳转或浏览器失焦会结束录制，每次开启最多 10 分钟。标签页音轨可能混有同标签其他声音。断线期间还未送达的媒体片段可能丢失。

PCV 自动在本地排队做转写和 OCR，识别失败会保留缺失说明。待处理片段从本机库恢复，媒体负载合计限制 2 GiB。识别成功的片段在处理后 24 小时清理原始负载，保留证据 ID、哈希和派生文字。可通过 [Agent 流媒体理解流程](AGENT_HANDOFF.md#流媒体片段理解) 查看结果或选择一帧交给 Agent。

扩展范围累积保存。添加新站点不会撤销旧范围；收窄范围需在浏览器扩展设置撤销对应权限。所有网站模式仍排除 localhost、127.0.0.1、IPv6 loopback、隐身窗口和浏览器内部页。

## 配对与故障

- 本机配对码用 Windows DPAPI 加密存于 .pcv/pairing.bin；扩展副本存于浏览器本地扩展存储，不同步到云端。这不是对证据数据库或网页内容的加密。
- 若提示端口占用，先关闭旧接收端或另一个 PCV 窗口；程序不会强行终止未知进程。旧的手动 watch 也应退出，避免同时写入。
- 用户来源已撤销或连接器已禁用时不会自动恢复；需明确恢复授权。
- 改用此启动器时需要配对一次，因为旧接收端使用每次变化的临时码。
- 脚本执行策略可能阻止未签名 PowerShell；本启动器不自动修改系统策略。也可在项目目录运行 `python -m pcv.desktop`。
- 没有开机自启、托盘服务、安装器或断线持久队列；接收端不在线时当前页面会稍后重试，切走后可能丢失未发送片段。

此版本为本地功能测试版本；完整的双击启动、窗口操作、真实浏览器权限及重启恢复仍需在目标设备联合验收。
