# 一键启动（Windows 原型）

需要 Python 3.11+（含 tkinter）与 Chrome/Edge。尚不是签名安装包；浏览器首次加载扩展和授予站点权限需用户操作，不会通过脚本绕过。

## 首次使用

1. 双击项目根目录 Start-PCV.cmd。一个窗口自动准备来源、连接器，运行接收端与入库程序，不需分别执行 CLI。
2. 在扩展管理页加载 browser-extension；已安装旧版则点击重新加载，并刷新网页。
3. PCV 窗口点击“复制首次配对码”，在扩展粘贴。选择“当前站点”或“所有 HTTP/HTTPS 网站”，点击“开始／添加范围”并确认浏览器权限。

## 日常使用

双击 Start-PCV.cmd。已保存的范围和配对继续有效，授权站点的新标签、刷新及跳转自动续采；只有前台可见且有焦点的页面被记录。最小化 PCV 窗口继续运行；关闭窗口停止接收和入库。扩展“暂停全部”停止发送，重启浏览器不会取消暂停。

扩展范围累积保存。添加新站点不会撤销旧范围；收窄范围需在浏览器扩展设置撤销对应权限。所有网站模式仍排除 localhost、127.0.0.1、IPv6 loopback、隐身窗口和浏览器内部页。

## 配对与故障

- 本机配对码用 Windows DPAPI 加密存于 .pcv/pairing.bin；扩展副本存于浏览器本地扩展存储，不同步到云端。这不是对证据数据库或网页内容的加密。
- 若提示端口占用，先关闭旧接收端或另一个 PCV 窗口；程序不会强行终止未知进程。旧的手动 watch 也应退出，避免同时写入。
- 用户来源已撤销或连接器已禁用时不会自动恢复；需明确恢复授权。
- 改用此启动器时需要配对一次，因为旧接收端使用每次变化的临时码。
- 脚本执行策略可能阻止未签名 PowerShell；本启动器不自动修改系统策略。也可在项目目录运行 `python -m pcv.desktop`。
- 没有开机自启、托盘服务、安装器或断线持久队列；接收端不在线时当前页面会稍后重试，切走后可能丢失未发送片段。

此版本为本地功能测试版本；完整的双击启动、窗口操作、真实浏览器权限及重启恢复仍需在目标设备联合验收。
